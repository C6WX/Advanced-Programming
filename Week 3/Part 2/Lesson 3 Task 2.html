Procedural Systems Mini-Project

Estimated Time: 3–6 hours

Submission: GitHub

Task Brief

Create a small interactive prototype that demonstrates a procedural system or algorithm. Choose one of the following options:

  • Procedural Audio — Generate dynamic music or ambience using FMOD, Wwise, or MetaSounds.
  • Wave Function Collapse — Implement a simple level, texture, or pattern generator using WFC.
  • Procedural Texture — Create a tool or script that generates textures or height maps (e.g., layered noise, gradients).
  • Sorting Algorithm / Leaderboard — Implement and visualise a sorting algorithm for a scoreboard or leaderboard, with persistent data (e.g. PlayerPrefs, JSON, Supabase, or Blueprints).

You may use any engine or framework (Unity, Unreal, Godot, Raylib, Python, etc.).

Deliverables

  • Working prototype (source code + build if applicable)

  • Media evidence:

    • .gif or short video of the system in action
    • Audio stems/recordings (if applicable)
    • Screenshots or generated assets

  • 500-word technical commentary (COMMENTARY.md) describing:

    • How your system works
    • Tools, algorithms, or APIs used
    • What is procedural or generative about your approach

Optional Ideas

  • Use real-time input (e.g. mouse, sound, data) to drive generation.
  • Combine two procedural systems (e.g. WFC + sound variation).
  • Visualise your algorithm’s process (e.g. sorting steps, texture layers).
