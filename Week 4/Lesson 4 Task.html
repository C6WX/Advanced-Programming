QA & Telemetry Mini-Project

Estimated Time: 3–6 hours

Submission: GitHub

Task Brief

Design and run a user testing and telemetry system for your Final Major Project (FMP) prototype. This task focuses on combining player feedback (QA testing) with performance or gameplay telemetry.

Your system should:

  • Include a user testing survey that collects:

    • Consent to participate and share data
    • Software version and platform tested
    • Quantitative data (e.g. ratings, scores, difficulty, FPS)
    • Qualitative feedback (e.g. comments, suggestions, bugs)

  • Implement one technical data collection feature, such as:

    • Benchmarking performance metrics (FPS, memory, CPU, frame time) written to a log
    • Collecting gameplay telemetry (player deaths, levels completed, items used) to a file or backend
    • A simple Supabase / JSON logger that records playtest sessions

Deliverables

  • Testing system and implementation (source code + any survey forms)

  • Media evidence:

    • .gif or short video showing data being collected or visualised
    • Screenshot(s) of the survey and/or log output

  • 500-word technical commentary (COMMENTARY.md) describing:

    • How you collected player feedback and consent
    • What telemetry or performance data was logged
    • Tools, frameworks, or services used (e.g. Supabase, Unity Analytics, Unreal Insights)
    • How this data could inform QA and game improvements

Optional Ideas

  • Use Google Forms, Typeform, or an in-game survey UI for user testing.
  • Create a simple CSV or JSON export of player telemetry.
  • Automate FPS logging with Unity’s Profiler, Unreal Insights, or a custom script.
  • Combine telemetry with backend storage for comparing multiple playtest sessions.
  • Visualise your data (e.g. frame rate graphs, heatmaps, or player stats) with something like Matplotlib / Python.
