Multiplayer Mini-Project

Estimated Time: 3–6 hours

Submission: GitHub

Task Brief

Design and implement a multiplayer micro-game within your chosen engine. This task focuses on using built-in networking tools and collaborating with at least one other student over a local network.

Your system should:

  • Implement multiplayer functionality using the networking features available in your engine.

  • Demonstrate one of the following:

    • Unity: Netcode for GameObjects, NGO with Relay, or Mirror for LAN play.
    • Unreal: Unreal’s built-in replication system, Blueprints networking, or Gameplay Ability System replication.
    • Godot / Other Engines: built-in high-level multiplayer APIs supporting LAN play.

  • Include at least one of these multiplayer game features:

    • Shared game state (e.g. score, timer, health).
    • Player actions replicated over the network (movement, interaction, combat, pickups).
    • A micro-game loop such as tag, racing, arena duel, obstacle challenge, or co-op puzzle.

  • Log relevant performance or telemetry data such as:

    • Ping / latency
    • Packet loss or disconnect events
    • Tick rate or replication frequency
    • Platform and hardware used during testing

Deliverables

  • Media evidence:

    • .gif or short video demonstrating the multiplayer game functioning with two players.
    • Screenshot(s) of the network session, replicated actions, or debug overlays (ping, net stats).

  • 500-word technical commentary (COMMENTARY.md) describing:

    • How networking was implemented or configured.
    • How players connect and what parts of the game are replicated.
    • Tools, frameworks, or APIs used (e.g. Netcode for GameObjects, Unreal Replication, Godot MultiplayerAPI).
    • How collaboration was carried out during development and playtesting.
