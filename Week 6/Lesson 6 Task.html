Artificial Intelligence Integration Mini-Project

Estimated Time: 3–6 hours

Submission: GitHub

Task Brief

Design and implement an AI-powered feature within your chosen project. This task focuses on integrating machine learning or generative AI locally or within your chosen engine.

Your system should:

  • Either load and run a local AI model using a framework such as Ollama, TensorFlow, or ONNX, or implement an AI system directly inside your project.

  • Demonstrate one of the following:

    • Unity / Unreal: integration of an AI system (e.g. NPC behaviour, procedural generation, dialogue, or adaptive gameplay).
    • Generative AI: use AI to create images, textures, models, sound, or code used within your project.
    • Local AI Deployment: run a local model via Ollama (e.g. Llama 3, Mistral, Phi-3) and communicate with it through a script or plugin.

  • Log relevant performance or telemetry data such as:

    • Model name and version
    • Inference time or response time
    • Number of tokens / samples generated
    • Platform and hardware used

Deliverables

  • Implementation files (Unity project, Unreal project, or standalone AI demo).

  • Media evidence:

    • .gif or short video demonstrating the AI feature or model in action.
    • Screenshot(s) of the model output, logs, or in-game integration.

  • 500-word technical commentary (COMMENTARY.md) describing:

    • How the AI model or system was implemented or connected.
    • What data was processed or generated.
    • Tools, frameworks, or APIs used (e.g. Ollama, TensorFlow, Hugging Face, Unity ML-Agents, Unreal ML Deformer).
    • How AI enhanced gameplay, creativity, or production workflow.

Optional Ideas

  • Compare local vs cloud-based model performance.
  • Use a chat or prompt system to drive gameplay interactions or procedural generation.
  • Visualise model performance (e.g. inference time graph or heatmap).
  • Train a simple model to influence in-game systems (e.g. adaptive difficulty or player behaviour prediction).
  • Evaluate the ethical and creative implications of AI use in your project (e.g. bias, authorship, originality).
