Portfolio Website with Auto Documentation

Estimated Time: 3–6 hours

Submission: Github

Task Brief

Create a polished personal portfolio website hosted on GitHub Pages.

Your site should:

  • Contain a landing page with your name, a short bio, and a way to contact you.
  • Include at least one project page with a short description and (optional) screenshot or link.
  • Use consistent visual styling (basic CSS or theme).
  • Generate automatic documentation from a small code sample (for example, using Doxygen, JSDoc, or pdoc).
  • Deploy the site and the generated docs to GitHub Pages automatically using GitHub Actions.

Deliverables

  • index.html and any supporting HTML/CSS/JS files for the portfolio site.

  • A src/ folder with a small documented code sample.

  • A GitHub Actions workflow file (.github/workflows/pages.yml) that:

    • Generates documentation from the code sample.
    • Publishes the site (including generated docs) to GitHub Pages.

  • A .gif or screenshot showing your portfolio site live in the browser.

  • A 400-500 Words dev log that is a critical reflection on the task and learned lessons. This should include what you planned to do, how you did it, what changes/adaptations you had to make, and what valuable skills/knowledge did you gain.

  • A README.md including:

    • The live GitHub Pages URL.
    • A short description of your site and its purpose.
    • Instructions to build the docs locally (e.g., doxygen Doxyfile or npx jsdoc src).

  • A docs/setup.md describing:

    • How the GitHub Actions workflow works.
    • How GitHub Pages is enabled in your repository.
    • Where the generated docs appear on the live site.
