Greedy Piggies

Platform: Steam(Unreleased) | Genre: Strategy, Gambling, Card Game
Tech Stack: Unreal Engine, Blueprints, GitHub, CI/CD, Jenkins

A multiplayer card game that was created by the whole year group at university. It was set to release to Steam but unforunately didn't make it on there. During this project, I programmed all of the multiplayer elements such as creating and joining lobbies and a server browser. I also worked with SteamWorks to prepare the game to be released and add some final touches to the multiplayer. I also managed the CI/CD side of the project, using Jenkins to check that the game is in working order.

Raylib: Space Invaders

Platform: itch.io | Genre: Arcade
Tech Stack: Raylib, C, Github

A unique version of Space Invaders created in Raylib for a university project. This version features API calls to access the current weather and wind levels to affect the bullet direction in the game, as if there was actual wind within the game.
