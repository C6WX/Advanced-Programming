Greedy Piggies

Platform: Steam (Unreleased) | Genre: Strategy, Gambling, Card Game
Tech Stack: Unreal Engine, Blueprints, GitHub, CI/CD, Jenkins

A multiplayer card game created by the whole year group at university. Set for release on Steam, I programmed all multiplayer elements, including creating/joining lobbies and a server browser. I integrated SteamWorks for final launch touches and managed the CI/CD pipeline using Jenkins to ensure build stability.

Steam Page GitHub Profile

Raylib: Space Invaders

Platform: itch.io | Genre: Arcade
Tech Stack: Raylib, C, GitHub

A unique version of Space Invaders created in Raylib for a university project. This version features live API calls to access current weather and wind levels, affecting bullet trajectory dynamically during gameplay as if affected by real-world wind.

Lurking In The Dark

Platform: itch.io | Genre: Horror, Puzzle
